# Shubham Kejriwal — personal website

Source for [perturber.github.io/shubham](https://perturber.github.io/shubham/), built with Jekyll on GitHub Pages.

- `_layouts/default.html`: page shell (header, nav, footer, dark-mode toggle)
- `_data/nav.yml`: navigation menu entries
- `assets/css/style.css`: all styles
- Pages: `index.md`, `research.md`, `publications.md`, `talks.md`, `activities.md`, `about.md`, `contact.md`
- `assets/Shubham_Kejriwal_CV.pdf`: CV linked from the nav

Local preview: `jekyll serve` and open http://localhost:4000/shubham/
